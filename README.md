# Git Revision Lab

Projet pratique destiné à réviser Git et GitHub.

## Objectif

Comprendre le cycle de versionnement, les branches, les fusions et le travail avec un dépôt distant.

## Méthode de travail

1. Vérifier l'état avec git status.
2. Examiner les différences.
3. Préparer uniquement les changements voulus.
4. Vérifier l'index.
5. Créer un commit cohérent.
